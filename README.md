✨ Features

- ➕ Create custom commands
- 📦 Manage your commands
- 🔍 Search commands
- ✏️ Edit commands
- 🗑️ Delete commands
- ⭐ Favorites
- 📁 Categories
- 📤 Export command packs
- 📥 Import command packs
- 📊 Command statistics
- 🧪 Test commands
- 🎨 Custom theme
- ℹ️ About / secret screen

📱 Installation

Open Termux and run:

pkg update
pkg install python

Then clone the repository:

git clone https://github.com/thewhuzii-lang/zafii-cmd.git
cd zafii-cmd

Run:

python zcmd.py

⚡ Quick Command

After installing the command launcher, use:

zcmd

📦 Command Packs

Create a pack:

zcmd-pack pack MyTools

Show available packs:

zcmd-pack packs

Install a pack:

zcmd-pack install ~/MyTools.zpack
